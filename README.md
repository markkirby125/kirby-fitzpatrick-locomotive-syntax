## Overview

The **Locomotive Syntax Engine** anchors technical explanations with an upfront subject-verb "locomotive engine" that pulls qualifying dependent clauses behind it, eliminating disorienting pre-modifier bloat and buried actions in engineering communication.

## Core Patterns

- **The 7-Word Engine Invariant**: Land actor and action in the first 7 words.
- **Unhitch Pre-Modifier Freight**: Move conditions and qualifications behind the main predicate.
- **Buried Predicate Rescue**: Replace "There is" and "It is" dummy pronouns with concrete active agents.
